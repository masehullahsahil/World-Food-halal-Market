# Analytics and Search Console Hooks

No GA4 Measurement ID or Google Search Console verification token is present in this repository.

When verified IDs are available, add them to the `<head>` of each static HTML page:

- Google Search Console: replace the existing verification hook comment with the supplied `google-site-verification` meta tag.
- GA4: replace the existing GA4 hook comment with the official `gtag.js` snippet containing the real Measurement ID.

Do not add placeholder IDs or unverified tracking tokens.
